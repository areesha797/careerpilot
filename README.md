# CareerPilot — Job Application Tracker

CareerPilot is a full-stack web application that helps job seekers organize job applications, track application progress, and identify skill gaps by comparing their skills with job descriptions.

## Problem Statement

Managing multiple job applications can be difficult when company details, application statuses, and job requirements are spread across different platforms. CareerPilot aims to bring this information into one organized dashboard.

## Planned Features

- Create, view, update, and delete job applications
- Track application statuses
- Search and filter applications
- Dashboard with application statistics and charts
- User authentication and private user-specific data
- Extract relevant skill keywords from job descriptions
- Compare required skills with a user's listed skills
- Display matched and missing skills
- Tests, responsive design, and deployment

## Technology Stack

- **Frontend:** Next.js, React, Material UI (MUI)
- **Backend:** Python, Django REST Framework
- **Database:** PostgreSQL
- **Charts:** Recharts
- **Skill Matching:** Python-based keyword matching
- **Version Control:** Git and GitHub
